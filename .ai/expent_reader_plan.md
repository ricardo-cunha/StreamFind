## Parser extension required

The TXT reader must support two Shimadzu export block families:

1. LC detector chromatograms:

```text
[LC Chromatogram(Detector A-Ch1)]
R.Time (min)    Intensity
```

2. MS chromatograms:

```text
[MS Chromatogram]
m/z    1-1MS(E+) TIC
R.Time(min)    Absolute Intensity    Relative Intensity
```

## Header mapping

Set `MS_CHROMATOGRAMS_HEADERS` as follows:

### LC UV/AD blocks

```text
signal_type = "UV" or "Analog"
chromatogram_type = "UV Trace" or "Analog Trace"
detector = parsed detector name
channel = parsed channel
units = parsed Intensity Units
wavelength_nm = parsed Wavelength(nm), otherwise NA
intensity_multiplier = parsed multiplier, otherwise 1
```

### MS blocks

```text
signal_type = "MS"
chromatogram_type = "TIC", "MRM", "XIC", or "MS Chromatogram"
detector = "MS"
channel = parsed trace label
units = "counts"
wavelength_nm = NA
intensity_multiplier = 1
precursor_mz / product_mz = parse from transition when available
polarity = parse from E+ or E- when available
```

Implement `asc::Reader` as a generic two-column chromatogram reader.

Expected ASC variants:

```text
time intensity
time,intensity
time;intensity
```

Detection/parsing rules:

1. Ignore empty lines.
2. Ignore comment/header lines starting with `#`, `[`, or alphabetic text.
3. Detect delimiter automatically:

   * tab
   * comma
   * semicolon
   * whitespace

# Phase 7 — Update `create_reader()`

In `reader.cpp`:

```cpp
std::unique_ptr<MS_READER> create_reader(const std::string& file_path) {
    const auto fmt = detect_format(file_path);

    if (fmt == "mzML") return std::make_unique<mzml::Reader>(file_path);
    if (fmt == "mzXML") return std::make_unique<mzxml::Reader>(file_path);
    if (fmt == "ShimadzuTXT") return std::make_unique<shimadzu_txt::Reader>(file_path);
    if (fmt == "ASC") return std::make_unique<asc::Reader>(file_path);
    if (fmt == "ShimadzuLCD") return std::make_unique<shimadzu_lcd::Reader>(file_path);

    throw std::runtime_error("Unsupported MS reader format: " + fmt);
}
```
