
Use this convention:

```text

```

For TXT/ASC/UV data, the time array is retention time in minutes, and intensity is detector response.

## 3.2 Update `detect_format()`

Detection priority:

```cpp
if extension == ".mzML" or ".mzml" -> mzML
if extension == ".mzXML" or ".mzxml" -> mzXML
if extension == ".txt" and file contains "[LC Chromatogram(" -> ShimadzuTXT
if extension == ".asc" -> ASC
if extension == ".lcd" and first 8 bytes are D0 CF 11 E0 A1 B1 1A E1 -> ShimadzuLCD
```

The uploaded TXT confirms the Shimadzu LCsolution export contains `[LC Chromatogram(...)]`, `Interval(msec)`, `# of Points`, `Intensity Units`, `Intensity Multiplier`, optional `Wavelength(nm)`, and then two columns: `R.Time (min)` and `Intensity`.

# Phase 4 — Add TXT chromatogram reader

Add namespace in `reader.h`:

```cpp
namespace shimadzu_txt {
struct Impl;

class Reader : public MS_READER {
public:
    explicit Reader(const std::string& file);
    ~Reader() override;

    int get_number_spectra() override;
    int get_number_chromatograms() override;
    int get_number_spectra_binary_arrays() override;

    std::string get_format() override;
    std::string get_type() override;
    std::string get_time_stamp() override;

    std::vector<int> get_polarity() override;
    std::vector<int> get_mode() override;
    std::vector<int> get_level() override;
    std::vector<int> get_configuration() override;

    float get_min_mz() override;
    float get_max_mz() override;
    float get_start_rt() override;
    float get_end_rt() override;
    bool has_ion_mobility() override;

    MS_SUMMARY get_summary() override;

    MS_CHROMATOGRAMS_HEADERS get_chromatograms_headers(std::vector<int> indices = {}) override;
    std::vector<std::vector<std::vector<double>>> get_chromatograms(std::vector<int> indices = {}) override;

    // Spectra methods return empty/default values.
};
}
```

Internally parse every section matching:

```text
[LC Chromatogram(...)]
```

For each block:

```text
Interval(msec)       -> interval_ms
# of Points          -> expected length
Start Time(min)      -> start_time
End Time(min)        -> end_time
Intensity Units      -> units
Intensity Multiplier -> intensity_multiplier
Wavelength(nm)       -> wavelength_nm, optional
R.Time (min)         -> start of data table
```

For the example file, there are at least two chromatogram sections: `Detector A-Ch1` and `AD1`.

### Important intensity rule

Store **scaled intensity** in the returned chromatogram:

```cpp
scaled_intensity = raw_intensity * intensity_multiplier;
```

But also keep `intensity_multiplier` in the header.

# Phase 5 — Add ASC chromatogram reader

Implement `asc::Reader` as a generic two-column chromatogram reader.

Expected ASC variants:

```text
time intensity
time,intensity
time;intensity
time<TAB>intensity
```

Detection/parsing rules:

1. Ignore empty lines.
2. Ignore comment/header lines starting with `#`, `[`, or alphabetic text.
3. Detect delimiter automatically:

   * tab
   * comma
   * semicolon
   * whitespace
4. Parse first two numeric columns.
5. If first column maximum is > 200, assume time is seconds and convert to minutes only if a setting or header indicates seconds. Otherwise leave as-is and document default as minutes.

Header defaults:

```cpp
signal_type = "UV";
chromatogram_type = "UV Trace";
detector = "";
channel = "";
units = "";
wavelength_nm = NaN;
interval_ms = inferred median diff * 60000 if time is min;
intensity_multiplier = 1.0;
```

# Phase 7 — Update `create_reader()`

In `reader.cpp`:

```cpp
std::unique_ptr<MS_READER> create_reader(const std::string& file_path) {
    const auto fmt = detect_format(file_path);

    if (fmt == "mzML") return std::make_unique<mzml::Reader>(file_path);
    if (fmt == "mzXML") return std::make_unique<mzxml::Reader>(file_path);
    if (fmt == "ShimadzuTXT") return std::make_unique<shimadzu_txt::Reader>(file_path);
    if (fmt == "ASC") return std::make_unique<asc::Reader>(file_path);
    if (fmt == "ShimadzuLCD") return std::make_unique<shimadzu_lcd::Reader>(file_path);

    throw std::runtime_error("Unsupported MS reader format: " + fmt);
}
```
