What Is Vibe Coding?

Describe the desired result in natural language, and let an AI agent generate and modify the code.

  • You state intent and expected behavior.
  • The agent writes, runs, and iterates.
  • You review, test, and accept the result.
You > Create a function to load a CSV file
Agent >
def load_csv(path):
with open(path) as f:
reader = csv.DictReader(f)
return list(reader)
You > Add a summary with row and column counts
Agent >
def summarize(rows):
cols = len(rows[0]) if rows else 0
return {"rows": len(rows), "cols": cols}

What Is MCP (Model Context Protocol)?

MCP standardizes the interface. The server connects the agent to the actual tool or data source, wherever it runs.
✦AI agent“How many samples are in batch_list.csv?”
→
MMCP serveroffers tools the agent can discover
→
▣Connected tool / data sourcereturns batch_list.csv for the agent to inspect
{
  "method": "tools/call",
  "params": {
    "name": "read_file",
    "arguments": { "path": "batch_list.csv" }
  }
}

How AI Agents Discover Tools via MCP

The key idea: the server advertises its available tools and schemas; the agent discovers them instead of hard-coding the integration.
✦AI agentstarts a connection with initialize
→
MMCP serverloads the tools it can provide
→
☷tools/listreturns names, descriptions, and schemas
→
✓AI agentselects a tool and calls it
{
  "tools": [
    "...",
    {
      "name": "read_file",
      "description": "Read a text file",
      "inputSchema": {
        "type": "object",
        "properties": { "path": { "type": "string" } },
        "required": ["path"]
      }
    },
    "..."
  ]
}

Take-home message

  • Vibe coding alone is not enough for FAIR analytical data processing: code needs explicit semantics, validation, and provenance.
  • An ontology standardizes meaning through harmonized definitions and knowledge-network graphs.
  • MCP gives AI agents controlled tools, reducing token-heavy instructions and constraining operations.
  • Ontology enriches MCP tools with semantic context, enabling more informed tool discovery and use.
  • streamfind is in active development, with ontology and MCP development at its core.
One semantic foundation can make analytical work reproducible, reusable, and AI-accessible.
